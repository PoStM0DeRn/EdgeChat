Проблема

The Problem

Почему облачные LLM не подходят для многих сценариев

Why cloud LLMs don't fit many use cases

Утечка данных

Data Leakage

Каждый запрос к ChatGPT/Gemini уходит на сервера третьих сторон. Для работы с конфиденциальными данными это неприемлемо.

Every request to ChatGPT/Gemini goes to third-party servers. Not acceptable for sensitive data.

Высокая стоимость

High Cost

Запускать LLM в облаке дорого: GPU-инстансы от $0.50/ч + API-рентабельность. Локальная модель бесплатна после покупки железа.

Cloud GPU instances start at $0.50/hr + API markup. Local models are free after hardware purchase.

Vendor Lock-in

Vendor Lock-in

Привязка к одному провайдеру: смена модели = переписывание интеграции. Локальная LLM — полный контроль.

Tied to one provider: switching models means rewriting integrations. Local LLM gives full control.

Нет офлайн-доступа

No Offline Access

Без интернета облачные LLM недоступны. Локальный AI работает всегда, даже в изолированных сетях.

No internet = no cloud LLM. Local AI works anywhere, even in air-gapped networks.

Решение

The Solution

Desktop Agent + SaaS = local AI, accessible from anywhere

Frequently Asked Questions

EdgeChat не отправляет ваши данные в облако — весь AI работает локально на вашем ПК. Мы предоставляем только прокси-слой для доступа из браузера. ChatGPT, напротив, обрабатывает все запросы на своих серверах. EdgeChat также поддерживает ComfyUI, RAG, и любые open-source модели.
EdgeChat never sends your data to the cloud — all AI runs locally on your machine. We only provide a proxy layer for browser access. ChatGPT processes everything on its servers. EdgeChat also supports ComfyUI, RAG, and any open-source model.
Не обязательно. Ollama поддерживает CPU-инференс для небольших моделей (Llama 3.2 3B, Qwen 2.5 7B). Для более крупных моделей (30B+) и ComfyUI желателен GPU от 8GB VRAM.
Not necessarily. Ollama supports CPU inference for smaller models (Llama 3.2 3B, Qwen 2.5 7B). For larger models (30B+) and ComfyUI, a GPU with 8GB+ VRAM is recommended.
Все данные остаются на вашем компьютере. SaaS-прокси не хранит сообщения — они передаются через WebSocket и сразу удаляются. Подключение шифруется (TLS). Токен Агента используется только для аутентификации.
All data stays on your machine. The SaaS proxy doesn't store messages — they pass through WebSocket and are discarded immediately. Connection is encrypted (TLS). The Agent token is used for authentication only.

Any model from Ollama (Llama 3, Mistral, Qwen, DeepSeek, Phi...) and LM Studio (OpenAI-compatible format). You choose the model in the Agent settings.
